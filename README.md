# SpaceX Falcon 9 First Stage Landing Prediction

## Project Overview
This project analyzes SpaceX Falcon 9 launch data and builds machine learning models to predict the successful landing of the first stage.

## Objectives
- Explore and analyze SpaceX launch data.
- Identify launch-site and yearly success trends.
- Perform SQL-based data analysis.
- Visualize launch locations using Folium.
- Build and compare machine learning classification models.
- Develop an interactive dashboard using Plotly and Dash.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL
- Folium
- Scikit-learn
- Plotly and Dash
- Google Colab

## Machine Learning Results

| Model | Test Accuracy |
|---|---:|
| Gradient Boosting | 88.89% |
| Decision Tree | 83.33% |
| Random Forest | 83.33% |
| Logistic Regression | 77.78% |

Gradient Boosting achieved the highest test accuracy of 88.89%.

## Project Workflow
1. Data collection
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. SQL analysis
5. Geographical visualization
6. Machine learning model development
7. Model evaluation
8. Dashboard development

## Dataset
The project uses the IBM Skills Network SpaceX dataset (`dataset_part_2.csv`).

## Conclusion
The analysis identifies patterns in Falcon 9 launch outcomes. Machine learning models were developed and evaluated to predict first-stage landing success.

## Limitations
- The dataset contains 90 launch records.
- Model results depend on the available dataset and train-test split.
- The dashboard was run as a local/Colab application and is not a permanent public deployment.
