# SpaceX Falcon 9 SQL Analysis

## 1. Launch Count by Site
```sql
SELECT LaunchSite, COUNT(*) AS launches
FROM launches
GROUP BY LaunchSite
ORDER BY launches DESC;
```

## 2. Success Rate by Site
```sql
SELECT LaunchSite, COUNT(*) AS launches,
ROUND(100.0*AVG(Class),2) AS success_rate_pct
FROM launches
GROUP BY LaunchSite
ORDER BY success_rate_pct DESC;
```

## 3. Success Rate by Orbit
```sql
SELECT Orbit, COUNT(*) AS launches,
ROUND(100.0*AVG(Class),2) AS success_rate_pct
FROM launches
GROUP BY Orbit
ORDER BY success_rate_pct DESC;
```

## 4. Payload Summary
```sql
SELECT Orbit,
ROUND(AVG(PayloadMass),2) AS avg_payload_kg,
MIN(PayloadMass) AS min_payload_kg,
MAX(PayloadMass) AS max_payload_kg
FROM launches
GROUP BY Orbit
ORDER BY avg_payload_kg DESC;
```

## 5. Top Flight Records
```sql
SELECT FlightNumber, LaunchSite, Orbit, PayloadMass, Class
FROM launches
ORDER BY FlightNumber DESC
LIMIT 10;
```
